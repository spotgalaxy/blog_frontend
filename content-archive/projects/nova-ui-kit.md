一套以温暖人文为基调的组件库与设计令牌体系。从色彩、字距到圆角的每一个细节，都在诉说着关于温度的故事。

## 项目背景

团队的产品线在过去两年快速扩张，各条线的界面风格逐渐漂移：同一个「主按钮」在三个产品里有五种写法。Nova 的目标是用一套统一的设计语言结束这种混乱。

## 我的贡献

作为设计系统的发起人和主要维护者，我负责了从设计令牌定义、组件 API 设计到文档站点搭建的完整链路，并推动它在三条产品线落地。

## 技术栈

- 设计侧：Figma Variables + Tokens Studio
- 工程侧：React + TypeScript + Storybook，CSS 自定义属性实现双主题
- 发布：Monorepo + Changesets 语义化版本管理

## 成果

上线半年后，三条产品线的新页面全部基于 Nova 开发，界面走查的样式问题下降了约 70%，新需求的页面搭建速度提升了近一倍。
