一个专为开发者打造的博客起点模板：五分钟部署，然后专心写作。

## 项目背景

很多开发者想写博客，却卡在建站这一步。DevBlog 把「能写字」之前的所有琐事都打包解决好。

## 我的贡献

独立完成全部开发，并维护了一年的版本迭代，根据用户反馈陆续加入了目录生成和草稿工作流。

## 技术栈

- Next.js + MDX，代码块带行号和复制按钮
- Giscus 评论（基于 GitHub Discussions，零后端）
- 自动生成 sitemap、RSS 与 OG 图片

## 成果

GitHub 上被 fork 了 200 多次，衍生出了十几个风格迥异的个人博客——看到它长成各种不同的样子，是这个项目最有趣的部分。
