中文排版是被严重低估的功课。同样是黑体，有的页面读起来行云流水，有的读两行就累——差别往往就在几个不起眼的细节上。

## 行高：中文需要比英文更大

汉字是方块字，字面率高、密度大，行高 1.5 会明显拥挤。正文行高建议 1.7 起步，长文阅读可以到 1.9。这个博客的正文行高就是 1.8。

## 中西文混排的间隙

中文与英文、数字之间留出一点空隙，会显著提升可读性。现在 CSS 有 `text-autospace` 可以做这件事，兼容性还不完美，但可以渐进增强：

```css
.article {
  text-autospace: normal;
}
```

## 标点悬挂与挤压

行首避免出现逗号、句号，行尾避免出现开括号——浏览器默认的 `line-break` 规则已经处理了大部分情况，但 `hanging-punctuation: first allow-end` 能让两端对齐的文本边缘更干净。

## 字重不要低于 400

中文笔画复杂，300 及以下字重在低分屏上会糊成一片。正文用 400，强调用 600，中间的 500 谨慎使用。

## 行长控制在 30–40 字

每行太长，换行时眼睛找不到下一行的开头；太短，阅读节奏被打碎。中文正文每行 30–40 个字符是比较舒适的区间，对应桌面端大约 640–720px 的内容宽度。
